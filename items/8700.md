# Проф. Рукоятка Tec-9(Нашивка)

![Item Image](../img/8700.webp?raw=true)

Легендарное улучшение для оружия: Проф. Рукоятка Tec-9(Нашивка)<br><br>Можно получить при объединении осколков предмета в количестве 5-и шт<br>или купить у игроков на центральном рынке.<br>Используется для установки на оружие в качестве улучшения.<br><br>Данное улучшение для оружия подходит только для скинов на Tec-9(слот 6).<br>При этом, характеристики улучшения будут распространяться на все типы оружия.<br><br>Данный предмет увеличивает точность оружия.<br>Уровень заточки улучшения: 0/5<br><br>Данное улучшение для оружия можно затачивать в любом магазине аммунации.<br>Для заточки вам потребуется предмет 'Заточка обвеса'.<br><br>С каждым новым уровнем улучшения предмет увеличивает точность оружия<br>в зависимости от типа оружия:<br>- Пистолеты: +10.0 процентов (Текущее: +10.0 процентов);<br>- Двойные пистолеты в две руки: +8.0 процентов (Текущее: +8.0 процентов);<br>- Автоматы и пистолеты-пулеметы: +7.0 процентов (Текущее: +7.0 процентов);<br>- Двойные автоматы и пистолеты-пулеметы: +8.0 процентов (Текущее: +8.0 процентов);<br>- Дробовики: +4.0 процентов (Текущее: +4.0 процентов);<br>- Двойные обрезы: +4.0 процентов (Текущее: +4.0 процентов);<br><br>Можно продавать, передавать и выкидывать.
