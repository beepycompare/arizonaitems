# Объект: Теплица

![Item Image](../img/9798.webp?raw=true)

Объект: Теплица<br><br>Можно получить путем крафта на верстаке или купить<br>у игроков на центральном рынке.<br><br>При использовании через инвентарь теплицу можно<br>установить в качестве объекта возле личного дома.<br>После установки вы сможете заходить в интерьер теплицы<br>и устанавливать там следующие объекты:<br><br>- Грядка хлопка;<br>- Грядка льна;<br>- Грядка с укропом;<br>- Яблочное дерево;<br>- Кокосовое дерево;<br>- Сливовое дерево.<br><br>Всего для установки будет доступно 16 слотов.<br><br>Чтобы установить объект внутри теплицы, вам необходимо будет<br>использовать его через инвентарь и выбрать свободный слот<br>для установки, находясь в интерьере теплицы. Данные объекты<br>могут быть установлены только внутри теплицы.<br><br>Обратите внимание! Для работы теплицы вам необходимо будет<br>пополнять баланс для оплаты электроэнергии.<br>Если на балансе будет недостаточно средств, то объекты установленные в теплице<br>не будут давать ресурсов.<br>Возле дома можно установить только 1 теплицу.<br><br>Разрешено передавать, продавать и выкидывать.
