# Объект: Магический дата центр

![Item Image](../img/9799.webp?raw=true)

Объект: Магический дата центр<br><br>Можно получить путем крафта на верстаке или купить<br>у игроков на центральном рынке.<br><br>При использовании через инвентарь дата центр можно<br>установить в качестве объекта возле личного дома.<br>После установки вы сможете заходить в интерьер дата центра<br>и устанавливать там Майнеры темной материи.<br><br>Всего для установки будет доступно 10 слотов.<br><br>Чтобы установить майнер внутри дата центра, вам необходимо будет<br>использовать его через инвентарь и выбрать свободный слот<br>для установки, находясь в интерьере дата центра. Майнер темной<br>материи может быть установлен только внутри магического дата центра.<br><br>Обратите внимание! Для работы дата центра вам необходимо будет<br>пополнять баланс для оплаты электроэнергии.<br>Если на балансе будет недостаточно средств, то объекты установленные в <br>маг. дата центре не будут давать ресурсов.<br>Возле дома можно установить только 1 магический дата центр.<br><br>Разрешено передавать, продавать и выкидывать.
