# Газонокосилка

![Item Image](../img/9805.webp?raw=true)

Газонокосилка<br><br>Можно получить случайным образом при открытии<br>золотой или серебряной рулетки, либо купить<br>у игроков на центральном рынке.<br><br>"Работает по самым новейшим нано-технологиям."<br><br>Газонокосилку можно использовать через инвентарь<br>и надеть на своего персонажа. Позволяет быстро<br>собирать созревший урожай с грядок и деревьев.<br><br>Состояние газонокосилки: -1 / 100<br><br>После сбора ресурсов с каждой грядки или дерева состояние уменьшается на -1 ед. <br>При достижении 0 ед. состояния, газонокосилку необходимо выкинуть.<br><br>Разрешено передавать, продавать и выкидывать.
