# Запечатанная эссенция Taxguard

![Item Image](../img/10832.webp?raw=true)

Запечатанная эссенция Taxguard<br><br>При использовании данного предмета через инвентарь<br>вы сможете распечатать эссенцию и случайным образом<br>определить цвет аксессуара для охранника Taxguard.<br><br>"Цвет внутри узнаешь, только когда сорвёшь печать."<br><br>Аксессуар Taxguard дает охраннику шанс получить дополнительный<br>предмет при открытии тайников. Чем реже цвет, тем выше шанс.<br><br>При распечатывании случайным образом будет<br>определен один из четырех цветов:<br><br>	Серый<br>	Белый<br>	Синий<br>	Фиолетовый<br><br>Розовый, Золотой и Красный цвета можно получить только<br>в крафте эссенций на верстаке.<br><br>Можно получить случайным образом при открытии Case Anarchy<br>или купить у игроков на центральном рынке.
